Channel Segregation Architecture

Under Hexagonal Architecture, the agent tools in agents/tools/ serve as the Google ADK Inbound Adapter. They do not contain raw HTTP requests or direct database queries — instead, they invoke the centralized app/services/ layer with an agent SecurityContext(actor="agent").

User-Only Channel:
User creation (POST /api/v1/users/) is deliberately excluded from agent tools so the LLM cannot provision accounts.
Agent-Only Channel:
inspect_cart_by_id() is accessible strictly by the AI agent for operational diagnostics and is omitted from public REST endpoints.
